
# Airline Passenger Satisfaction Analysis

## Project Overview

This project analyzes airline passenger satisfaction using Python, Pandas, NumPy, Matplotlib, Seaborn, and SQL.

The main objective is to understand passenger behavior, identify factors affecting customer satisfaction, analyze airline service quality, and discover areas where airlines can improve their services.

## Project Objectives

- Analyze passenger demographics and travel patterns.
- Understand overall customer satisfaction.
- Compare satisfaction across travel classes and customer types.
- Analyze departure and arrival delays.
- Evaluate airline service quality.
- Identify important business insights from the data.

## Dataset

The dataset contains airline passenger information, including:

- Passenger demographics
- Customer type
- Travel purpose and class
- Flight distance
- Departure and arrival delays
- Airline service ratings
- Passenger satisfaction

**Dataset Source:** [Kaggle - Airline Passenger Satisfaction](https://www.kaggle.com/datasets/mysarahmadbhat/airline-passenger-satisfaction)
